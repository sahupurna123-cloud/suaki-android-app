# Suaki Android prototype
Flutter Android prototype for the Suaki SEO services store.

GitHub Actions builds a release APK on pushes to main or manually from Actions → Build Suaki Android APK → Run workflow.

Download the artifact named suaki-android-apk from a successful workflow run and extract app-release.apk.

This prototype contains a Suaki home screen, sample service catalogue, local demo cart, and account/support placeholders. It does not yet authenticate WooCommerce customers, submit real orders, process payments, or sync live inventory. Prices and service descriptions are sample content.
